03 / ACCESS CONTROL

Team access

For security, accounts are invited in Supabase Authentication and then explicitly added to the admin_users allowlist. Only allowlisted accounts can manage content.

  1. Open Supabase → Authentication → Users.
  2. Invite the team member by email.
  3. Copy that user's UUID.
  4. In Supabase SQL Editor, run the allowlist insert shown in SUPABASE-SETUP-BN.md.

Never share a database password, secret key or service_role key with a team member or in this page.
